# Vansh Kalra – Portfolio

A simple, responsive personal portfolio website built with plain HTML, CSS and JavaScript. It introduces me, lists my skills, and showcases my projects.

## About me

I'm Vansh Kalra, a student at KIET Deemed to be University, Ghaziabad. I enjoy building clean, useful things for the web and solving problems in C++.

## Features

- Clean, minimal design with a hero section, About, Skills, Projects and Contact sections
- Responsive layout that works on phones, tablets and desktops
- Automatic light and dark mode based on your device settings
- Nav link highlights the section you are viewing
- Smooth scrolling and a short entrance animation (respects reduced-motion settings)
- No frameworks or build tools needed

## Tech stack

- HTML5
- CSS3
- JavaScript (vanilla)

## Project structure

```
.

├── style.css    # Styling, colors, layout and dark mode
```
